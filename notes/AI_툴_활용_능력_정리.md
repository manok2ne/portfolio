# AI 툴 활용 능력 정리 (포트폴리오·면접용)

2026-10-20 기준, 데스크탑의 PROJECT(ZEN WAY · DUET WISH), VIDEO, IMAGE, 캐러셀, CHARACTER, SOUND 폴더와 `~/프로젝트_ZEN WAY`, 첨부 영상(short1.mp4)을 읽기 전용으로 확인하고 정리했어요. 파일은 하나도 수정하지 않았어요.

## 1. 수준을 이렇게 나눠요

별점이나 % 게이지는 근거가 없어 보여서 면접관이 잘 믿지 않아요. 대신 아래 3단계 라벨에 **근거 한 줄**을 붙이는 방식을 추천해요.

| 라벨 | 뜻 | 면접에서 말할 수 있는 것 |
|---|---|---|
| **설계** | 툴로 반복 가능한 규칙·검수 체계를 직접 만들었다 | 규칙 문서, 검수 프롬프트, 실패하고 고친 사례 |
| **제작** | 툴로 실제 결과물을 만들어 배포하거나 게시했다 | 만든 결과물, 내가 직접 판단하고 고친 부분 |
| **이해** | 구조를 읽고 수정 요청을 할 수 있다 | 어떤 역할을 하는 툴인지, 어디에 연결되는지 |

디자인과 개발은 말씀하신 대로 "전문가는 아니지만 이해하고 직접 만들 수 있다"는 **제작** 수준으로 잡았어요.

## 2. 카테고리별 평가

### ① 서비스 기획: **설계**
| 툴 | 확인한 근거 |
|---|---|
| ChatGPT | 지역별 관광지·음식점·숙소·교통 리서치 프롬프트, Duet Wish 가사 최종 검수 |
| Claude | 플레이스 데이터 입력 규칙(비짓인포·하이라이트·게팅히어), 데이터 품질 검수 프롬프트, 젠웨이 공통규칙, 카드뉴스 생성기 PRD |

- 강점: **두 모델을 역할 분담해 교차 검수**했어요(Claude 작성 → GPT 검수). "AI 답을 그대로 쓰지 않고 검수 구조를 만들었다"는 말의 근거가 돼요.
- 면접 한 줄: "리서치와 데이터 입력을 AI에 맡기되, 입력 규칙과 검수 프롬프트를 먼저 만들어 품질을 관리했습니다."

## 4. 포트폴리오에 표시하는 방법

추천 형태는 **"AI 워크플로" 4단 카드**예요. 기획 → 제작 프로세스 → 디자인 → 개발 순서로 가로로 놓으면 "툴을 아는 사람"이 아니라 "툴로 서비스를 끝까지 만든 사람"으로 읽혀요.

카드 하나의 구성:
```
[서비스 기획]                       설계
ChatGPT · Claude
리서치 프롬프트와 데이터 입력 규칙을 만들고,
두 모델 교차 검수로 품질을 관리
→ ZEN WAY 보기
```

- 라벨: 설계 / 제작 두 종류만 써요. 기획·프로세스는 "설계", 디자인·개발은 "제작".
- 툴 이름은 칩(태그)으로, 근거는 한 줄로, 마지막에 해당 프로젝트 링크를 달아요.
- 개발 카드에는 "Non-developer · 코드 읽기와 API 연동 가능"처럼 수준을 솔직하게 적는 편이 오히려 신뢰를 줘요.
- 툴 칩은 카드당 6개 이하로 줄이고, 나머지(Capacitor, Redis 등)는 프로젝트 상세 페이지에서 보여줘요.
